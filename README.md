# Moni
listen your way.

On Windows with WampServer installed, double-click `start-player.bat` and open the app at `http://localhost:8000/`. Keep the server window open while listening. If you open `index.html`, `songs.html`, or `player.html` directly, the app redirects to its local web-server address; make sure the server has been started first.

Alternatively, run the project from its folder with `php -S localhost:8000` or use XAMPP, then visit the matching local web address.

Place audio tracks in the `song/` folder and cover images in the `cover/` folder.

Choose a track on the song list to open it in the dedicated player. If your browser blocks automatic playback after navigation, press Play on the player page.
