# Moni
listen your way.

Run the project from a local web server (for example, `php -S localhost:8000` or XAMPP) rather than opening the files directly in the browser. Browsers block media playback from `file://` URLs, so the audio files will not load if you open the page directly.

Place audio tracks in the `song/` folder and cover images in the `cover/` folder.

Choose a track on the song list to open it in the dedicated player. If your browser blocks automatic playback after navigation, press Play on the player page.
